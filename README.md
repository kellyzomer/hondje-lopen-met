# Hondje lopen met Kel

Eenvoudige statische website voor GitHub Pages. De homepage staat in `index.html`; de tarieven, over-mij- en contactpagina staan in `tarieven.html`, `over-mij.html` en `contact.html`. De vormgeving staat in `styles.css`.

## Lokaal bekijken

Start vanuit deze map:

```sh
python3 -m http.server 8000
```

Open daarna <http://localhost:8000> en <http://localhost:8000/tarieven.html>.

## Foto's bijwerken

De homepage gebruikt de drie foto's in `images/`. Vervang de bestanden en pas de afbeeldingsnamen en alt-teksten in `index.html` aan als je later andere foto's kiest.

Controleer vóór publicatie of `hondjeuitlaten@kellyzomer.com` bereikbaar is.
